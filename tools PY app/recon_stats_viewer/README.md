# TWS Recon Live Viewer

Desktop Python app that watches your INIDBI2 output file and displays live recon squad stats.

## What It Shows

- Squad size alive and total
- Casualties
- Squad type (classification)
- Squad health status
- Avg health percent
- Strength percent and label
- Composition counts: infantry, static, armour, mech, air, naval
- Last seen timestamp

## File Layout

- app.py: live viewer UI
- config.json: watched INI path and refresh interval
- requirements.txt: no third-party packages required

## Run

From this folder:

```powershell
py app.py
```

If py is unavailable:

```powershell
python app.py
```

## Configure INI Path

1. Open app.
2. Click Browse and select TWS_ReconIntel.ini.
3. Click Save Config.

Default path in config.json:

- D:/Arma 3/@inidbi2/db/TWS_ReconIntel.ini

Adjust to your actual server/mod install path if needed.

## Real-Time Behavior

- UI refreshes every refresh_seconds from config.
- It only re-parses when file timestamp changes.
- You can force a read with Refresh Now.

## INIDBI2 Read Guidance

The app reads the plain text INI generated by INIDBI2, specifically sections:

- Meta
- TargetStats

Your exporter already writes those sections from recon_export_inidbi2.sqf.

If nothing appears:

1. Confirm mission is running and exporter is active.
2. Confirm INI path points to live server file.
3. Confirm file is updating in a text editor.
4. Confirm TargetStats section exists.
