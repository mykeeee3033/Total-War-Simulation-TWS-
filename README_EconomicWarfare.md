## Overview

The Economic Warfare Systems add sophisticated resource management and strategic facility tracking to your ALiVE mission. This system introduces 6 new resource types and 8 strategic building roles that create dynamic supply chains and economic targets.

## New Resource Types

### 1. **Manpower** 
- Represents available soldiers for deployment
- Reduced by casualties (70% casualty-to-manpower ratio)
- Required for spawning reinforcements
- Gained through resupply operations

### 2. **Munitions**
- Advanced ammunition for heavy weapons
- Required for armor and aircraft production
- Generated by munitions factories
- Consumed in heavy combat operations

### 3. **Fabrications**
- Advanced materials for vehicle construction
- Required for producing vehicles and aircraft
- Generated by industrial facilities
- Used in repair operations

### 4. **Research & Development (RND)**
- Intelligence and technology points
- Generated by operational R&D facilities
- Provides enemy intelligence reveals
- Unlocks advanced capabilities

### 5. **Electricity** 
- Power grid capacity affecting production
- Generated by power stations
- Affects production rates of all facilities
- Can create operational delays when insufficient

### 6. **Construction**
- Construction workers for repairs and building
- Required for facility repairs
- Temporary deployment reduces available workers
- Auto-returned after repair completion

## Strategic Building Roles

### 1. **Munitions Factory**
- **Function**: Produces advanced ammunition
- **Power Required**: 50 units
- **Production**: 100 ammo units/hour
- **Strategic Value**: Critical for sustained operations

### 2. **Fuel Refinery**
- **Function**: Produces fuel for vehicles
- **Power Required**: 75 units  
- **Production**: 50 fuel units/hour
- **Strategic Value**: Essential for mobile operations

### 3. **Vehicle Plant**
- **Function**: Manufactures and repairs vehicles
- **Power Required**: 100 units
- **Production**: 2 vehicles/hour
- **Resource Cost**: 50 materials + 20 fuel

### 4. **Aircraft Plant**
- **Function**: Produces and maintains aircraft
- **Power Required**: 150 units
- **Production**: 0.5 aircraft/hour (1 every 2 hours)
- **Resource Cost**: 100 materials + 50 fuel

### 5. **Power Station**
- **Function**: Provides electricity to other facilities
- **Power Output**: 500 units (powers multiple factories)
- **Strategic Value**: Force multiplier for all production

### 6. **Radar Site**
- **Function**: Air defense and enemy detection
- **Range**: Configurable (default 10km)
- **Strategic Value**: Intelligence and air defense

### 7. **HQ Node**
- **Function**: Command and control center
- **Strategic Value**: Coordination hub for operations

### 8. **Logistics Hub**
- **Function**: Supply distribution center
- **Strategic Value**: Supply chain efficiency

## Integration with Existing Systems

### ALiVE Integration
- **Sector Control**: Production only occurs in faction-controlled areas
- **OPCOM Objectives**: Facilities auto-assigned near OPCOM objectives  
- **Dynamic Targeting**: Economic facilities become strategic targets

### Supply System Integration
- **Resupply Operations**: Now affected by manpower levels
- **Helicopter Operations**: Can be enhanced with advanced resources
- **Supply Efficiency**: Reduced when critical resources are low

### Reinforcement System Integration
- **Manpower Cost**: Reinforcements consume manpower resources
- **Spawn Timing**: Affected by available construction workers
- **Equipment Quality**: Determined by munitions/fabrications availability

## Usage Instructions

### Automatic Initialization
The economic systems initialize automatically when the mission starts:

1. **Server Startup**: `initServer.sqf` loads the economic systems
2. **ALiVE Detection**: Waits for ALiVE framework to be ready
3. **Auto-Assignment**: Automatically assigns roles to buildings near OPCOM objectives
4. **Resource Setup**: Initializes starting resources for all factions

### Manual Commands

#### Check Economic Status
```sqf
[] execVM "showEconomicStatus.sqf"
```
Displays current resources and facility counts for all factions.

#### Test All Systems
```sqf
[] execVM "testEconomicSystems.sqf"  
```
Runs comprehensive tests of all economic features (server only).

#### Manual Facility Assignment
```sqf
[building, "munitionsFactory", "BLUFOR"] call TWS_fnc_assignObjectRole;
```

#### Resource Management
```sqf
// Check resources
_resources = ["OPFOR"] call TWS_fnc_getResources;

// Add resources  
["BLUFOR", "munitions", 100] call TWS_fnc_modifyResource;

// Consume resources (returns success/failure)
_success = ["OPFOR", "manpower", 50] call TWS_fnc_consumeResource;
```

## Configuration

### Resource Starting Values
Edit in `extendedResources.sqf` around line 70:
```sqf
_resources set ["manpower", 100];        // Starting soldiers
_resources set ["munitions", 500];       // Starting ammunition  
_resources set ["fabrications", 300];    // Starting materials
_resources set ["electricity", 1000];    // Starting power
```

### Production Rates
Edit in `objectRoles.sqf` around line 35:
```sqf
_munitionsFactory set ["productionRate", 100]; // Units per hour
_fuelRefinery set ["productionRate", 50];
// etc.
```

### Update Intervals
Edit in `extendedResources.sqf` around line 25:
```sqf
TWS_intervals set ["RNDTickInterval", 300];           // 5 minutes
TWS_intervals set ["ElectricityUpdateInterval", 180]; // 3 minutes  
```

## Strategic Gameplay Impact

### Economic Warfare Targets
- **Primary Targets**: Power stations (affect multiple facilities)
- **Secondary Targets**: Munitions factories (limit heavy operations)
- **Support Targets**: Fuel refineries (reduce mobility)

### Resource Scarcity Effects
- **Low Manpower**: Reduced reinforcement capability
- **Low Munitions**: Cannot produce advanced vehicles
- **No Power**: All production halted in affected areas
- **Low Construction**: Cannot repair damaged facilities

### Area Control Requirements
- Facilities only produce when faction controls surrounding area (60% control required)
- Lost sectors automatically reduce production capacity
- Contested areas may have intermittent production

## Troubleshooting

### Common Issues

**"Economic systems not ready"**
- Wait for ALiVE to fully initialize
- Check that OPCOM instances exist
- Verify initServer.sqf is loading the systems

**"No facilities found"**  
- Run auto-assignment: `[] call TWS_fnc_autoAssignRoles`
- Manually assign test facilities using the test script
- Check that buildings exist near OPCOM objectives

**Resources not updating**
- Verify faction controls the area around facilities
- Check power station availability
- Ensure facilities haven't been destroyed

### Debug Commands

